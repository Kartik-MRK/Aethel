{# Shared display macros. `digest` is the typographic rule for hashes on this site: the leading characters carry full ink and the tail recedes. That is how these values are actually used -- a reader compares a prefix and treats the rest as machine detail -- so the type makes the useful part findable without hiding the fact that the whole 64-character value is present and copyable. It is one macro rather than a filter so the markup stays in the template layer, and one definition rather than per-page markup so the treatment cannot drift between pages. #} {% macro digest(value, size='', head=12, label='') %} {%- if value -%} {{ value[:head] }}{{ value[head:] }} {%- else -%} {#- An em dash is the visual form of "no value", but it is not the spoken one: read aloud it is either silence or the words "em dash". `aria-label` will not fix that here -- a bare span has the `generic` role, and ARIA prohibits naming generic elements, so assistive technology is entitled to drop the label. Clipped real text is honoured everywhere. -#} —not recorded {%- endif -%} {% endmacro %} {# A status pill.
